Online Train Ticket Reservation System

Project Description-
The Online Train Ticket Reservation System is a Java J2EE based web application
that allows users to search trains, check seat availability, and book train tickets online.
The system also provides an admin module to manage train details such as adding, updating, and deleting trains.
It uses a database for storing user, train, and booking information and runs on an Apache Tomcat server.

🔹 Features

User Module:
User registration and login
Search trains between stations
Check seat availability
Fare enquiry
Book train tickets
View booking history
Change password

Admin Module:
Admin login
Add trains
Update train details
Delete or cancel trains
View all trains

🔹 Technologies Used

Frontend: HTML, CSS, Bootstrap
Backend: Java (J2EE), Servlet, JDBC
Database: Oracle SQL
Server: Apache Tomcat
IDE: Eclipse Enterprise Edition

🔹 Software Requirements

Java JDK 8+
Eclipse EE
Apache Tomcat 8+
SQL Workbench / Oracle SQL
Web Browser

🔹 How to Run the Project

Import the project into Eclipse EE
Configure Apache Tomcat server
Set up the database and tables
Run the project on the server
Open browser and access the application

🔹 Conclusion

This project provides a simple and efficient way to manage online train ticket reservations and helps in understanding Java web application development using J2EE.
